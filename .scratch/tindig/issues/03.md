## What to build

## Acceptance criteria

- [x] Show exact product/variant before saving an alias; no automatic learning from an unconfirmed guess.
- [x] Persist approved alias mappings; collisions return choices rather than silently selecting a product.
- [x] Unknown terms remain explicit and catalog prices remain authoritative.
- [x] Verify alias creation, reuse after restart, rejection, and ambiguous mappings through lookup actions.
