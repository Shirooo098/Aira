## What to build

## Acceptance criteria

- [ ] Connect reviewed transcript to catalog/alias lookup; show unknown or ambiguous results without guessed prices.
- [ ] Supported short commands use the validated fast path; no local language model is required for this slice.
- [ ] Measure utterance end to visible lookup result against the under-three-second target; report every tested result and cold/warm conditions.
- [ ] Record agreed sample size and accuracy/latency acceptance interpretation before declaring success; demonstrate airplane mode with Wi-Fi disabled.

- #3 — Teach and reuse owner-confirmed product aliases
